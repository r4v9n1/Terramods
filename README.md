# Terramods

Terramods is a Windows mod manager for Valheim by R4V9N1. It installs and updates mods from Thunderstore,
Nexus Mods and Hexium and verifies every installed file.

This repository holds the **downloads only**: see [Releases](https://github.com/r4v9n1/Terramods/releases) for the
installer (`Terramods-Setup-<version>-win-x64.exe`), the portable zip and `SHA256SUMS.txt`.

Terramods checks this page at startup and shows *Up to date* or *Update available* in its header.
